Installation

Run the command below in your terminal to start the installation.

curl -fsSL https://example.com/install.sh | sh

How to open Terminal on Mac

  1. Press Command (⌘) + Space to open Spotlight Search.
  2. Type "Terminal" and press Return to launch it.
  3. Once the Terminal window is open, run the command above.

Installation via Terminal command

  1. Copy the command by clicking the Copy button.
  2. Paste it into Terminal (Command (⌘) + V) and press Return.
  3. Wait for the installation to finish.
